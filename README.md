# Open Memory Format (OMF)

**Your memories, in files you own.** OMF is an open format for a life's
record — journal days, notes, and the people and places in them — stored as
plain Markdown files in a folder you control. Human-readable, app-agnostic, yours
forever.

**→ [Read the 0.2 spec](https://orma-day.github.io/orma-community/spec/0.2/)**
 · [Website](https://orma-day.github.io/orma-community/)
 · [Example vault](./example-vault)

> **Status: draft / unstable.** 0.2 documents the format the first Orma
> release reads and writes, and flags the decisions still to settle before a
> stable 1.0.
> Don't treat 0.x as a stability guarantee.

## What it is

A **memory vault** is a plain folder of Markdown files (plus a few binaries and
one JSON settings file). OMF is a *profile* of three things developers already
know:

- **CommonMark** for bodies,
- **YAML** frontmatter for structured fields,
- `[[wikilinks]]`, `![[embeds]]` and `> [!callouts]` for cross-references
  (Obsidian-compatible).

A vault is portable by construction — just files in a folder, in any storage
the user controls. Any app that follows this spec can read and write the same
vault. It is a **portability / migration** format, not a concurrent
multi-writer protocol (no merge/conflict semantics; last-write-wins).

## Roadmap to 1.0

Reaching a stable **1.0** means settling the
[open questions](spec/0.2/OMF-0.2-draft.md#10-open-questions) and shipping the
conformance artifacts:

- [ ] Resolve the open questions (`type` redundancy, bare mentions, settings
      scope, note filenames, section embeds)
- [ ] **Validator** — checks a vault against the spec
- [ ] **Reference parser** — a library, extracted from the reference app
- [x] **Example vault** — see [`example-vault/`](./example-vault)

Propose format changes with a [spec change issue](https://github.com/orma-day/orma-community/issues/new?template=spec_change.yml).

## Editing the spec

Edit `spec/<version>/OMF-<version>-draft.md`, then regenerate its page:

    pip install markdown-it-py
    python3 scripts/build_spec.py 0.2
